Перед генерацией кода проверь:

□ Не нарушает ли код Dependency Rule?

□ Не добавляет ли бизнес-логику в Cog?

□ Не импортирует ли Domain Infrastructure?

□ Не создает ли новую абстракцию без необходимости?

□ Не использует ли SQLAlchemy вне Infrastructure?

□ Можно ли удалить этот модуль без изменения остальных?

□ Не появляется ли новый utils.py?

□ Соответствует ли код существующему стилю проекта?

□ Если можно сделать проще — сделать проще.

□ Если решение требует комментариев для понимания — его нужно упростить.
