идей. Актуальный состав фич и инструкции по запуску — в корневом
[README](../../README.md); правила слоёв — в [ARCHITECTURE.md](../ARCHITECTURE.md).

Все запланированные фичи реализованы. Из внепрограммных задач остаются только
**хостинг** (вынести бота на постоянный сервер) и **настоящий TLS** (заменить
самоподписанный сертификат панели на выданный CA для реального домена).

Реализованные планы оставлены как исторический контекст и аргументация решений —
не удаляем, помечаем статусом.
