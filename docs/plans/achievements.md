# Ачивки сервера с рендер-карточками

> **Статус:** 🟡 черновик каталога (обсуждается, до кодирования)

Достижения участника на сервере, которые открываются за действия в уже
существующих системах бота и показываются **картинкой** — тем же Pillow-рендером,
что и карточка `/rank` ([rank_card.py](../../src/infrastructure/rank_card.py)).

Две карточки одним рендером: **«получено!»** при анлоке и **`/achievements`** —
витрина-коллекция значков. Модуль — своя вертикаль `domain → application → cog`,
подписка на события через `IEventBus`, per-server тумблер `achievements`.
Существующие фичи по возможности не правятся.

## Легенда стоимости

| Значок | Что значит |
|---|---|
| ✅ | ловится уже публикуемым доменным событием — дешевле всего |
| ⚙️ | нужен счётчик прогресса (маленький репозиторий) или чтение существующего состояния |
| 🔌 | нужен новый аддитивный `bus.publish(...)` в чужой фиче (безопасно, но это «касание») |

**Тиры** (рабочий вариант — словарь редкостей находок, для консистентности с
ботом): `common` · `uncommon` · `rare` · `legendary`.

## Чат и общение

Крутятся вокруг общения **с Попосей** (единственный per-user чат-сигнал, что
трекается — очки отношений) и альбома. Персональный подсчёт сообщений
**сознательно не вводим** (см. открытые вопросы) — ачивки за участие, не за флуд.

| Ачивка | Условие | Тир | Стоимость |
|---|---|---|---|
| Первое слово | впервые написать Попосе (упоминание/реплай) | common | 🔌 хук в ai_chat |
| Заболтала до потолка | упереться в дневной лимит очков (20/сутки) | uncommon | 🔌 при начислении очков |
| Ночной собеседник | заговорить с Попосей ночью (3–5 утра) | rare | 🔌 (время в момент начисления) |
| В альбоме Попоси | твоё сообщение набрало реакций и попало в альбом | uncommon | 🔌 (хук альбома несёт автора) |
| Хит сервера | 3 / 10 сообщений в альбоме | rare | ⚙️ счётчик |
| Возвращение | вернуться после долгого отсутствия | uncommon | 🔌 (activity уже детектит для welcome-back) |
| Старожил | N дней на сервере (дата входа — из Discord) | uncommon / rare | ⚙️ (join date, без нового трекинга) |

## Стартовый набор (MVP)

Только ✅ и ⚙️ — **ноль правок чужих когов** (подписка на существующие события +
пара счётчиков + чтение состояния):

- Ступени близости (6) · Единственный · Открытая душа · По душам
- Первая находка · Ночной охотник · Редкая/легендарная удача · Подарок Попосе
- Первый трек · Меломан
- Завсегдатай войса · Голос сервера · Житель войса

~17 осмысленных ачивок, целостный срез, нулевой риск для существующих фич.
Вторая волна — 🔌-набор (кино, секретка, ДР, каморки, дуэли, первый разговор):
каждый пункт = один аддитивный `bus.publish(...)`.

## Открытые вопросы

1. **Тиры** — словарь находок (common/uncommon/rare/legendary) или свой
   (бронза/серебро/золото)? *Черновик использует первый.*
2. **Скрытые ачивки** — вводить как класс (не видны до анлока) или все видны
   сразу списком «что можно получить»?
3. **Иконки** — цветной эмодзи-шрифт (Noto Color Emoji, Pillow 12
   `embedded_color=True`), набор PNG-ассетов значков или рисованные медали
   геометрией? Текущий рендер `/rank` эмодзи вычищает — это единственный новый
   технический кусок против существующей карточки.
4. **Бэкфилл** — при выкатке ретроактивно открыть заслуженное (эксклюзив,
   находки, войс-часы): разовый проход или ленивая проверка при первом
   `/achievements`.

## Рендер карточек (решено)

Единый стиль для всех карточек, по мотивам эталонного мокапа: тёмный
градиентный фон с декором, «стеклянная» карточка, значок в светящемся кольце,
пилюля редкости, крупная статистика, футер (сервер + дата). Тир задаёт акцент.

- **Движок: HTML/CSS → Playwright + Chromium → PNG.** Pillo­w этот уровень
  (glassmorphism, градиенты, свечения) чисто не даёт. Цена — headless-браузер в
  образе (~300–400 МБ); принято осознанно ради качества и шаблонной гибкости.
- **`/rank` унифицируется** на тот же движок: один стиль и один пайплайн, старый
  Pillow-рендер ([rank_card.py](../../src/infrastructure/rank_card.py)) выводится.
- **Иконки** — inline-SVG в шаблоне (ноты/наушники/Discord/галочка рисуются
  вектором с градиентом): проблема «эмодзи-квадратиков» из Pillow снята.
- Мокап-эталон: `scratchpad/card.png` (пример «Меломан», rare).

## Порядок сборки

1. **Фундамент рендера**: модуль `card_render` (async: пул/лончер Chromium через
   Playwright, HTML-шаблон → PNG-байты), HTML-шаблон карточки, Dockerfile
   (`playwright install --with-deps chromium`), зависимость в requirements.
2. **Миграция `/rank`** на шаблон — как проверка фундамента на живой команде.
3. **Домен ачивок**: каталог + `UnlockedAchievement` (модель + миграция).
4. **Логика**: подписчики на события `IEventBus` + счётчики прогресса, бэкфилл.
5. **Ког**: `/achievements` (витрина) + карточка-уведомление при анлоке,
   тумблер `achievements`, персона-фразы.
6. **Тесты** на каждый слой.

## Решённое

- **Персональный подсчёт сообщений — НЕ вводим.** Ачивки вида «болтун 1k
  сообщений», «стрик N дней», «сова/жаворонок» требовали бы завести per-user
  трекинг сообщений, а бот сознательно этого не делает (server-wide агрегат,
  `/forgetme`, privacy-домен). Чат-ачивки строим только на уже трекаемых
  сигналах (очки общения с Попосей, альбом, дата входа).
