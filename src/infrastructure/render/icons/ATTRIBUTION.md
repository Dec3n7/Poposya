# Иконки карточек (собственные)

Собственные векторные эмблемы карточек ачивок. Авторские SVG для проекта
Poposya P, лицензия — как у репозитория.

Файлы `<key>.svg` — самодостаточные SVG, `viewBox="0 0 36 36"` (как у Twemoji).
Ключ — это поле `icon` в каталоге ачивок (`src/domain/achievements/catalog.py`);
обычно совпадает с `id` ачивки. Резолвер — `render/cards.py`, функция
`_resolve_icon`: сначала ищет здесь, затем в `../twemoji/` (фолбэк для
эмодзи-значений). Иконка вставляется инлайн в SVG карточки и растеризуется
librsvg в renderer-сервисе.

Требования к новому ассету: только инлайн-пути/фигуры, `linearGradient`/
`radialGradient`/`clipPath`; без внешних `href`, `<script>`, `<foreignObject>`,
сетевых ресурсов и CSS-фильтров (librsvg их не гарантирует).
