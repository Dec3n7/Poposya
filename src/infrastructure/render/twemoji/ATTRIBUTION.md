# Twemoji

Эмодзи-эмблемы карточек (ачивки, `/premium`) — из набора **Twemoji**.

**CC-BY 4.0** (https://creativecommons.org/licenses/by/4.0/).
Источник: https://github.com/twitter/twemoji (версия 14.0.2).

Здесь хранится ПОДМНОЖЕСТВО SVG — только эмодзи, используемые в карточках.
Теперь это **фолбэк**: основные эмблемы ачивок — собственные иконки в `../icons/`,
а эмодзи-Twemoji берутся, когда поле `icon` содержит эмодзи-символ (например,
колонки `/premium`). Оба варианта вставляются инлайн в SVG карточки (см.
`../cards.py`, функция `_icon`/`_resolve_icon`), поскольку librsvg не растеризует
цветной эмодзи-шрифт. При добавлении новой ачивки с новым эмодзи положите сюда
соответствующий `<codepoint>.svg` из Twemoji.
