# Twemoji

Эмодзи-эмблемы карточек (ачивки, `/premium`) — из набора **Twemoji**.

© Twitter, Inc и другие участники. Графика Twemoji лицензирована под
**CC-BY 4.0** (https://creativecommons.org/licenses/by/4.0/).
Источник: https://github.com/twitter/twemoji (версия 14.0.2).

Здесь хранится ПОДМНОЖЕСТВО SVG — только эмодзи, используемые в карточках. Они
вставляются инлайн в SVG карточки (см. `../cards.py`, функция `_emoji`), поскольку
librsvg не растеризует цветной эмодзи-шрифт. При добавлении новой ачивки с новым
эмодзи положите сюда соответствующий `<codepoint>.svg` из Twemoji.
