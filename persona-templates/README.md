# Шаблоны персон

Готовые примеры персон Попоси — их можно **сразу импортировать** в панели или
взять за основу для своего персонажа.

## Файлы

| Файл | Что это |
|------|---------|
| [`example-minimal.json`](example-minimal.json) | Минимальный валидный шаблон: только имя + промпт + пара атрибутов, без переопределения фраз. Показывает, что заполнять всё необязательно. |
| [`example-warm.json`](example-warm.json) | «Рэй» — тёплый, дружелюбный характер (контраст меланхоличной Попосе). С несколькими переопределёнными фразами. |
| [`example-dry.json`](example-dry.json) | «Кол» — сухой, немногословный смотритель. Пример «строгого» голоса. |

Это **примеры-заготовки**, а не «официальные» персоны. Переименовывайте, правьте
и удаляйте их как угодно — при импорте всегда создаётся **новая** персона, а
дефолтная «Попося» остаётся нетронутой.

## Как использовать

1. Панель → сервер → вкладка **Персона** (видна только оператору бота).
2. Раскройте **«Библиотека персон»** → **«Импорт»** → **«Выбрать файл…»** →
   выберите нужный `.json` → **«Импортировать»**.
3. Выберите импортированную персону в списке → **«Сделать активной здесь»**.

Хотите начать с чистого листа? Там же есть кнопка **«Скачать шаблон»** — она
отдаёт пустую заготовку со всеми полями и подсказками. Заполните её (можно
отдать другому человеку) и загрузите обратно тем же «Импортом».

## Формат (кратко)

```jsonc
{
  "name": "Имя персоны",
  "prompt": "системный промпт: характер и манера речи (пусто = дефолт Попоси)",
  "chime_prompt": "когда сама решает вступить в чат (пусто = дефолт)",
  "attributes": {
    "display_name": "имя в тексте реплик",
    "signature": "подпись-эмодзи",
    "accent_color": "#RRGGBB",        // цвет эмбедов
    "presence": ["строки Discord-статуса"]
  },
  "phrases": [
    // необязательно: переопределение отдельных строк каталога.
    // key — из реестра PHRASE_SPECS; в тексте допустимы только плейсхолдеры
    // этого ключа (например {name}); mode — ai_then_static | static | silent.
    { "key": "activity.welcome", "value": "Привет, {name}!", "mode": "ai_then_static" }
  ]
}
```

Импорт устойчив к ошибкам: незнакомые ключи, чужие плейсхолдеры и кривые
значения **не роняют** загрузку — панель покажет отчёт, что именно отброшено и
почему. Незаполненные строки заготовки (`value: null`) просто пропускаются.

> Эти файлы проверяются тестом `tests/test_persona_templates.py`: каждый обязан
> импортироваться **без единой отброшенной строки** — иначе CI краснеет. Так
> примеры не устаревают вслед за реестром фраз.
